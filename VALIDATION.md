## Реальный трафик протоколов

Тест protocol-e2e запускает настоящие systemd units через LinuxAdapter. Серверные конфиги берутся из штатного генератора; только ACME заменён тестовым сертификатом. Правила ACL не ослабляются: тестовый HTTP origin использует документационный IP 203.0.113.10 на loopback одноразового runner.

| Клиент | Версия | Результат |
|---|---|---|
| NaiveProxy | v150.0.7871.63-1 | TLS, авторизация и HTTP-трафик через SOCKS 1080 прошли |
| mieru | 3.37.0 | JSON, официальный импорт mierus и HTTP-трафик через SOCKS 1081 прошли |
| Xray | 26.3.27 | VLESS + XHTTP + REALITY, HTTP-трафик через SOCKS 1082 по IPv4 и IPv6 прошли |

У NaiveProxy SSL_CERT_FILE указывает на тестовый доверенный сертификат; проверка TLS не отключается. REALITY target — локальный HTTP/2 TLS 1.3 сервер; агент проверяет его сертификат и ALPN. Неверное имя сертификата и цель без h2 отклоняются.

После замены всех трёх протокольных секретов старые клиенты не передают трафик, новые передают. Перед отрицательными проверками подтверждается, что локальные SOCKS listeners и клиентские процессы работают. При пустом списке Xray/mita остановлены, NaiveProxy-доступ отсутствует.

## Локальные проверки Windows

Node.js 24.19.0: все восемь тестов прошли. В браузере проверены вход, три ссылки импорта, XHTTP URI, раздельные вкладки нативных JSON и предупреждение о неприменённой конфигурации.

## Границы результата

CI не подтверждает настройки пользовательского VPS. Отдельно проверяются публичный DNS и AAAA, ACME, firewall провайдера/VPS, доступность REALITY target из нужной сети и поддержка XHTTP конкретным приложением. QUIC, Android/iOS, нагрузка и долговременная эксплуатация не проверялись.

Применение проверено с реальным LinuxAdapter; аварийный откат в протокольном стенде не вызывался, его порядок проверен отдельным тестом с имитацией адаптера. Обновитель не является мигратором движков и сохраняет их текущие версии.
